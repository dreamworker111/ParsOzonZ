# Ozon Parser

Приложение с графическим интерфейсом для парсинга товаров Ozon с «Баллами за отзыв».

## Запуск

1. Дважды кликните `run.bat` — установит зависимости и запустит приложение.
2. Или вручную:
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   python main.py
   ```

## Сборка EXE

Запустите `build.bat`. Исполняемый файл будет в папке `dist\OzonParser.exe`.

## Использование

1. Выберите охват:
   - включите **«Парсить конкретный магазин»** и вставьте ссылку продавца;
   - выключите флажок, чтобы загрузить общий каталог и собирать товары всех
     продавцов Ozon через `https://www.ozon.ru/seller/`. Ссылка магазина в
     этом режиме не нужна. Этот режим выбран по умолчанию.
2. Нажмите **Загрузить каталог** — появится дерево категорий.
3. Выберите категории (если ничего не выбрано — парсятся все).
4. Укажите диапазон цен и количество товаров.
5. Выберите режим авторизации (без / с авторизацией).
6. Нажмите **Запустить**. Кнопка сменится на **Остановить**.

## Результат

Файл XLSX сохраняется в `C:\Ozon\` с именем вида:
`Ozon баллы 30.07.2026 16_56.xlsx`

## Авторизация

- **Desktop / без авторизации** — обычный гостевой режим или открытый Chrome для Ozon.
- **Мобильный / без авторизации** — чистый мобильный контекст без cookies настольного браузера.
- **Мобильный / с авторизацией**:
  1. Выберите «Мобильный» и «С авторизацией».
  2. Нажмите «Войти в мобильный Ozon».
  3. Выполните обычный вход в открывшемся окне. Если Ozon показывает CAPTCHA
     или блокировку, пройдите проверку вручную.
  4. Не закрывая окно Ozon, вернитесь в приложение и нажмите OK только после
     открытия личного кабинета.

Приложение проверяет наличие действующей авторизационной сессии (токен + user id)
и сохраняет отдельный мобильный профиль. Пароли и коды подтверждения приложение не
запрашивает и не сохраняет. Если вход ещё не виден, можно подтвердить повторно;
отмена не считается ошибкой. При истёкшей сессии вход нужно повторить.

## Требования

- Windows 10 / 11
- Python 3.10+
