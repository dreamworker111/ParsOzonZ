# Ozon Parser

Приложение с графическим интерфейсом для парсинга товаров Ozon с «Баллами за отзыв».

## Скачать и запустить (без Python)

1. Откройте страницу релизов: https://github.com/dreamworker111/ParsOzonZ/releases
2. Скачайте файл **`OzonParser.exe`** из последнего релиза.
3. Убедитесь, что на ПК установлены **Windows 10/11** и **Google Chrome** (или Edge).
4. Дважды кликните `OzonParser.exe`.

Готово — IDE и Python не нужны.

Если Windows покажет предупреждение SmartScreen:
- нажмите **Подробнее** → **Выполнить в любом случае**.

Результаты парсинга сохраняются в папку `C:\Ozon\`.

## Сборка EXE у себя

1. Дважды кликните `build.bat`.
2. Готовый файл появится в `dist\OzonParser.exe`.
3. Его можно копировать на другие компьютеры.

Либо используйте `OzonParser.bat`: если EXE ещё нет, он сначала соберёт приложение, затем запустит его.

## Запуск из исходников (для разработки)

1. Дважды кликните `run.bat` — установит зависимости и запустит приложение.
2. Или вручную:
   ```bash
   pip install -r requirements.txt
   playwright install chromium
   python main.py
   ```

## Использование

1. По умолчанию парсятся товары всех продавцов через `https://www.ozon.ru/seller/`.
   При загрузке категорий собирается **полный каталог со всеми ветками**.
2. Чтобы ограничить одним магазином, включите **«Парсить конкретный магазин»** и укажите ссылку продавца.
3. Нажмите **Открыть Chrome** (для Desktop) и дождитесь загрузки Ozon.
4. Нажмите **Загрузить категории**.
5. Отметьте нужные категории (при желании переименуйте через ✎).
6. Укажите диапазон цен и количество товаров **с баллами** (до 100 000 на категорию).
7. Нажмите **Запустить парсер** — в результат попадут только товары с бонусными баллами за отзыв.

## Результат

Файл XLSX сохраняется в `C:\Ozon\` с именем вида:
`Ozon баллы 30.07.2026 16_56.xlsx`

Сессии и настройки также хранятся в `C:\Ozon\`.

## Авторизация

- **Desktop / без авторизации** — обычный гостевой режим или открытый Chrome для Ozon.
- **Мобильный / без авторизации** — чистый мобильный контекст без cookies настольного браузера.
- **Мобильный / с авторизацией**:
  1. Выберите «Мобильный» и «С авторизацией».
  2. Нажмите «Войти в мобильный Ozon».
  3. Выполните обычный вход в открывшемся окне. Если Ozon показывает CAPTCHA
     или блокировку, пройдите проверку вручную.
  4. Не закрывая окно Ozon, вернитесь в приложение и подтвердите вход после
     открытия личного кабинета.

## Требования

- Windows 10 / 11
- Google Chrome или Microsoft Edge
- Для сборки/разработки: Python 3.10+
